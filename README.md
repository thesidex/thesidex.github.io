# Rainforest House — Listing Site

Frontend-only site for the Costa Rica property listing, built to replace [thesidex.github.io](https://thesidex.github.io/).

## Quick start

1. Add your photos to the [`images/`](images/) folder (see [images/README.md](images/README.md) for filenames).
2. Open `index.html` in a browser, or serve locally:

   ```bash
   npx serve .
   ```

3. Deploy to GitHub Pages by pushing this repo and enabling Pages on the `main` branch (root `/`).
